# Product & Project Management Portfolio

A curated, documentation-only portfolio presenting selected product, project, and technology initiatives. Source code, internal working files, credentials, client data, and private implementation artefacts remain in their original private repositories.

## Portfolio principles
- Public pages describe product context, problem framing, scope, workflows, delivery approach, and lessons.
- Claims about personal ownership, release status, client acceptance, and measurable outcomes are included only when independently verified and approved for disclosure.
- Screenshots, diagrams, and documents are published only when sharing rights are clear and sensitive information is removed.
- Related prototypes and iterations are grouped as one product story rather than counted as separate launches.

## How to read these case studies
Each page separates known project context from proposed or unverified capabilities. It is a public-facing product-management narrative, not a mirror of the private source repository.

## Confidentiality
No source code is published here. Public documentation can still be copied, so only publish material that is approved for public disclosure. Private repository links and internal documents are intentionally omitted.
