# Candidate Connect & ITPL — Candidate Experience

**Product area:** Candidate engagement and application experience  
**Private workspaces:** [Candidate Connect](https://github.com/Chan0304/candidate-connect-pro) · [ITPL Candidate Experience](https://github.com/Chan0304/ITPL) · [ITPL/Kods integration workspace](https://github.com/Chan0304/ITPL_Kods-)

## Product context
These repositories are grouped as one candidate-experience case study because their documented domains overlap around candidate engagement, application experience, and a related integration workspace. Their exact technical and delivery relationship remains to be confirmed.

## Product problem and intended value
Candidate-facing processes can become fragmented across applications, communications, and internal recruitment operations. A coherent candidate experience should make the application journey clear and support consistent handling by the responsible team.

## Scope to validate
Candidate onboarding and application capture, candidate profile information, status communication, internal review workflows, administrative access, and integration boundaries are candidate areas for discovery. The ITPL repository is documented as an empty repository shell; no implemented feature is claimed for it.

## Product-management approach
Map candidate and internal-user journeys, define data fields and consent, agree status transitions and ownership, document acceptance criteria, validate integrations, and test the end-to-end application and follow-up process.

## Privacy and controls
Candidate records can contain personal information. Apply role-based access, data minimisation, consent and retention policies, secure document handling, and auditability.

## Status and evidence
The repositories' README files establish their candidate-related purpose but do not verify feature completeness, production use, client acceptance, or measurable recruitment outcomes. The grouping is a portfolio-level classification, not confirmation that all repositories are one deployed system.
